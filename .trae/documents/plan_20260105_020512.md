# 修改方案：添加模型上传提示信息

## 1. 修改 index.html

**修改内容**：

在模型选择区添加一个提示信息元素，用于显示"暂无其他模型，联系开发者添加"的提示。

**具体修改**：

在模型选择下拉框下方添加一个提示元素，初始隐藏。

```html
<!-- 模型选择下拉框 -->
<select id="modelSelect" class="model-select" disabled>
  <option value="">请先选择模型文件夹</option>
  <!-- 模型列表将通过JavaScript动态生成 -->
</select>

<!-- 新增：模型提示信息 -->
<p id="modelHint" class="model-hint hidden">暂无其他模型，联系开发者添加</p>
```

## 2. 修改 app.js

### 2.1 修改 `initDefaultModel` 函数

**修改内容**：

在初始化默认模型时，显示提示信息，因为此时只有默认模型，没有其他模型。

**具体修改**：

```javascript
function initDefaultModel() {
  const modelSelect = document.getElementById('modelSelect');
  const modelHint = document.getElementById('modelHint');
  
  // 清空下拉框
  modelSelect.innerHTML = '';
  
  // 添加默认模型
  models = [defaultModel];
  
  const defaultOption = document.createElement('option');
  defaultOption.value = defaultModel.id;
  defaultOption.textContent = defaultModel.name;
  modelSelect.appendChild(defaultOption);
  
  // 启用下拉框
  modelSelect.disabled = false;
  
  // 自动选择默认模型
  modelSelect.value = defaultModel.id;
  selectedModel = defaultModel;
  
  // 显示提示信息，因为只有默认模型
  modelHint.classList.remove('hidden');
}
```

### 2.2 修改 `loadModelsToSelect` 函数

**修改内容**：

根据模型数量显示或隐藏提示信息。如果只有默认模型，显示提示信息；如果有其他模型，隐藏提示信息。

**具体修改**：

```javascript
function loadModelsToSelect(modelNames) {
  const modelSelect = document.getElementById('modelSelect');
  const modelHint = document.getElementById('modelHint');
  
  // 清空下拉框
  modelSelect.innerHTML = '';
  
  // 添加模型选项，包含默认模型
  models = [];
  modelNames.forEach((name, index) => {
    const modelId = index === 0 ? 'model_default' : `model_${index}`;
    models.push({ id: modelId, name: name });
    
    const option = document.createElement('option');
    option.value = modelId;
    option.textContent = name;
    modelSelect.appendChild(option);
  });
  
  // 启用下拉框
  modelSelect.disabled = false;
  
  // 默认选中第一个模型（默认小爱助手模型）
  modelSelect.value = 'model_default';
  selectedModel = defaultModel;
  
  // 根据模型数量显示或隐藏提示信息
  // 如果只有默认模型，显示提示信息
  if (modelNames.length <= 1) {
    modelHint.classList.remove('hidden');
  } else {
    modelHint.classList.add('hidden');
  }
}
```

### 2.3 修改 `handleFolderChange` 函数

**修改内容**：

在处理文件夹选择时，如果没有找到其他模型，确保提示信息显示。

**具体修改**：

```javascript
function handleFolderChange(event) {
  const files = event.target.files;
  if (files.length > 0) {
    // 使用默认模型路径作为选中文件夹
    selectedFolder = defaultModelPath;
    
    // 更新选中文件夹显示
    document.getElementById('selectedFolder').textContent = selectedFolder;
    
    // 提取模型文件名
    const modelNames = [];
    const seenNames = new Set();
    
    for (const file of files) {
      // 获取文件名（不含路径）
      const fileName = file.name;
      
      // 只添加唯一的文件名
      if (!seenNames.has(fileName)) {
        seenNames.add(fileName);
        modelNames.push(fileName);
      }
    }
    
    // 加载模型到下拉框，同时保留默认模型
    loadModelsToSelect([defaultModel.name, ...modelNames]);
  }
}
```

## 3. 修改 styles.css

**修改内容**：

添加模型提示信息的样式，使其与整体风格一致。

**具体修改**：

```css
/* 模型提示信息样式 */
.model-hint {
  margin-top: 8px;
  font-size: 13px;
  color: hsl(var(--muted-foreground));
  text-align: center;
  font-style: italic;
}

```

## 4. 预期效果

1. 初始加载时，模型选择区显示默认模型，并显示提示信息"暂无其他模型，联系开发者添加"。

2. 当用户点击"选择模型文件夹"按钮并选择文件夹后：

   * 如果文件夹中没有其他模型文件，提示信息继续显示。

   * 如果文件夹中有其他模型文件，提示信息隐藏，显示所有模型选项。

3. 提示信息使用斜体、灰色文字，居中显示，与整体风格一致。

## 5. 技术要点

1. 使用 `hidden` 类控制提示信息的显示和隐藏。
2. 根据模型数量动态判断是否显示提示信息。
3. 保持提示信息的样式与整体设计风格一致。
4. 确保在各种情况下提示信息都能正确显示
