# AI声音克隆系统

## 项目简介

这是一个基于AI的声音克隆系统，允许用户上传音频样本并生成自然流畅的克隆语音。

## 功能特性

- **声音克隆**：上传音频样本，输入文本，生成克隆语音
- **声音库**：管理和浏览保存的声音模型

## 技术栈

- 前端：HTML、CSS、JavaScript

## 快速开始

### 启动前端服务

```sh
# 进入项目目录
cd capture-creators-main

# 在项目目录中启动HTTP服务器
python -m http.server 8000
```

前端界面将可通过 `http://localhost:8000` 访问。

## 使用说明

### 声音克隆

1. 在左侧导航栏点击"声音克隆"
2. 选择模型文件夹（默认路径：`D:\1\ai study\GPT-SoVITS-v2pro-20250604\GPT_weights_v2Pro`）
3. 从下拉列表中选择一个声音模型
4. 输入需要合成的文本
5. 点击"开始合成"按钮（当前功能已暂时禁用）

### 声音库

1. 在左侧导航栏点击"声音库"
2. 上传音频样本用于训练新模型
3. 点击"模型训练"按钮开始训练（当前功能已暂时禁用）

### 模型选择问题

**问题**：无法选择模型或模型列表为空

**解决方案**：

1. 确保模型文件夹路径正确
2. 确保模型文件夹中包含有效的模型文件
3. 重新选择模型文件夹

## 注意事项

1. 音频文件大小限制为10MB，支持MP3、WAV、M4A格式
2. 文本输入限制为500个字符
3. 当前语音合成功能已暂时禁用，请使用外部工具进行语音合成
4. 当前模型训练功能已暂时禁用，请使用外部工具进行模型训练
