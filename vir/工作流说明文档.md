# 直播带货数字人对口型工作流说明

## 概述
这是一个基于ComfyUI的直播带货数字人对口型工作流，结合了文本转语音、图像转视频和音频同步技术，实现数字人主播与产品展示的完美同步。

## 核心流程
1. **文本转语音** - 使用VoxCPM TTS生成语音
2. **音频处理** - 分离、处理和优化音频
3. **图像预处理** - 加载和缩放产品展示图片
4. **视频生成** - 基于静态图像生成动态视频
5. **音频同步** - 实现口型与语音的精确同步
6. **视频合成** - 输出最终的带货视频

## 详细组件说明

### 📢 语音合成模块

#### 节点244 - 文本输入
```json
"string": "1块钱，买不了吃亏，1块钱，买不了上当。\n全场只要1块钱。\n1、2、3，上链接~！"
```
**作用**: 定义直播带货的话术内容，支持多行文本，可自定义销售话术。

#### 节点257 - VoxCPM TTS语音合成
```json
"model_name": "VoxCPM1.5"
```
**作用**: 
- 使用先进的VoxCPM1.5模型将文本转换为自然语音
- 支持中文语音合成，音质清晰自然
- 配置参数：CFG=2，推理步数=10，设备=cuda

#### 节点260 - Whisper语音识别
```json
"model": "whisper-large-v3"
```
**作用**: 
- 对生成的语音进行语音识别
- 用于提取语音特征，为后续的口型同步提供数据支持
- 支持多语言识别

### 🎵 音频处理模块

#### 节点243 - 原始音频加载
```json
"audio": "d83dcf88bd097430d2999be8191d005aec563067868ebe45add5d178c0ea048a.wav"
```
**作用**: 加载原始音频文件，可能包含背景音乐或参考音频。

#### 节点261 - 音频分离
```json
"chunk_length": 10,
"chunk_overlap": 0.1
```
**作用**: 
- 将长音频分割成短片段进行处理
- 设置片段长度为10秒，重叠度为10%
- 提高音频处理的精度和效率

#### 节点262 - 音频裁剪
```json
"start": 0,
"end": 6.1
```
**作用**: 
- 精确裁剪音频片段
- 从0秒开始，到6.1秒结束
- 确保音频时长与视频长度匹配

#### 节点288 - 音频选择器
**作用**: 在原始音频和TTS生成的音频之间选择，用于音频对比和优化。

#### 节点351 - 音频时长获取
**作用**: 获取音频的实际时长，用于后续的视频帧数计算。

### 🖼️ 图像处理模块

#### 节点343 - 图像加载
```json
"image": "a278141117f141d0ed8cca6cf0c69b7958026b84db3f46347cf8b65dcb73cb3d.png"
```
**作用**: 加载产品展示的静态图片，可以是模特展示产品的照片。

#### 节点204 - 图像缩放和比例调整
```json
"aspect_ratio": "original",
"scale_to_length": 720
```
**作用**: 
- 保持原始宽高比进行缩放
- 将较长边缩放到720像素
- 使用lanczos高质量缩放算法
- 确保输出视频的分辨率统一

### 🎬 视频生成模块

#### 节点120 - MultiTalk模型加载
```json
"model": "InfiniteTalk/Wan2_1-InfiniTetalk-Single_fp16.safetensors"
```
**作用**: 加载Infinite Talk模型，专门用于多人对话和口型同步的视频生成。

#### 节点122 - WanVideo主模型加载
```json
"model": "aniWan14BFp8E4m3fn_i2v480pNew.safetensors"
```
**作用**: 
- 加载主要的WanVideo生成模型
- 配置：fp16精度、关闭量化、offload设备加载
- 集成LoRA和MultiTalk模型支持

#### 节点138/255 - LoRA模型加载
```json
"lora": "Wan21_I2V_14B_lightx2v_cfg_step_distill_lora_rank64.safetensors"
```
**作用**: 加载专门的LoRA微调模型，优化图像到视频的转换效果。

#### 节点128 - WanVideo采样器
```json
"steps": 4,
"cfg": 1.0000000000000002,
"scheduler": "unipc"
```
**作用**: 
- 配置视频生成参数：4步采样，CFG=1.0
- 使用UniPC调度器提高生成效率
- 设置随机种子确保结果可重现
- 配置图像嵌入、文本嵌入和音频嵌入

### 🧠 特征编码模块

#### 节点173 - CLIP视觉编码器
```json
"clip_name": "clip_vision_h.safetensors"
```
**作用**: 加载CLIP视觉模型，用于图像特征的深度编码。

#### 节点193 - CLIP视觉特征编码
```json
"strength_1": 1,
"strength_2": 1,
"ratio": 0.5000000000000001
```
**作用**: 
- 使用CLIP对输入图像进行特征编码
- 双重强度编码确保特征质量
- 设置编码比例为50%

#### 节点346 - 文本编码器
```json
"model_name": "umt5-xxl-enc-bf16.safetensors"
"positive_prompt": "模特正在做产品展示，进行电商直播带货"
```
**作用**: 
- 使用UMT5模型对文本提示进行编码
- 设置正向提示：模特正在做产品展示，进行电商直播带货
- 配置负向提示避免不期望的结果

#### 节点194 - MultiTalk音频嵌入
```json
"multi_audio_type": "para",
"normalize_loudness": true
```
**作用**: 
- 将音频转换为MultiTalk模型所需的嵌入格式
- 支持并行音频处理
- 标准化音频响度

### 📊 辅助计算模块

#### 节点248/249 - 帧数计算
```json
"value": "a*25+25"
```
**作用**: 
- 根据音频时长计算视频帧数
- 公式：(音频秒数 × 25fps) + 25帧
- 确保视频与音频时长匹配

#### 节点137 - Wav2Vec模型
```json
"model": "TencentGameMate/chinese-wav2vec2-base"
```
**作用**: 加载中文Wav2Vec模型，用于音频特征的深度理解。

"purge_cache": true,

## 使用方法

### 1. 环境准备
- 安装ComfyUI
- 下载所需模型文件到指定目录
- 确保GPU支持CUDA

### 2. 输入准备
- 准备产品展示图片
- 编辑直播话术文本
- 可选：准备背景音频

### 3. 运行流程
- 在ComfyUI中导入此工作流
- 上传产品图片
- 修改话术文本
- 运行工作流生成视频

### 4. 输出结果
- 生成对口型的产品展示视频
- 视频包含自然的中文语音
- 适合用于电商直播带货

## 优化建议

1. **文本优化**: 根据产品特点编写吸引人的销售话术
2. **图像质量**: 使用高清的产品展示图片
3. **音频调整**: 适当调整语音的语调和语速
4. **参数调优**: 根据GPU性能调整批处理大小和精度设置

## 注意事项

- 确保有足够的GPU显存（建议16GB+）
- 模型文件较大，首次加载需要较长时间
- 生成视频耗时较长，需要耐心等待
- 建议使用高质量的输入图片以获得最佳效果
